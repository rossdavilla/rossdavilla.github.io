# CLAUDE.md

This repo publishes https://rossdavilla.github.io/, a directory of every website in Ross's public GitHub repos.

- `index.html` is generated by `scripts/build.mjs` from the GitHub API plus `data/sites.json`. Never edit it by hand. Rebuild with `GITHUB_TOKEN=$(gh auth token) node scripts/build.mjs`.
- `.github/workflows/rebuild.yml` rebuilds every six hours, on every push to `main`, and on manual dispatch, then deploys through GitHub Pages (Actions source).
- Uncurated repos land under "Just added" and uncurated pages under "More pages". When one shows up (the build log and job summary list them), add it to `data/sites.json`: pick a category, write a one-sentence summary in the same voice as the others, and add links with clear labels.
- Keep non-public pages off the directory with the repo's `ignore` globs: mockups, templates, drafts, review sheets, and instructor-only dashboards.
