# CLAUDE.md

This repo publishes https://rossdavilla.github.io/, a directory of every web app in Ross's public GitHub repos: one 3:4 card per app (title, screenshot, short description), grouped and filterable by class tag.

- `index.html` is generated by `scripts/build.mjs` from the GitHub API plus `data/sites.json`. Never edit it by hand. Rebuild with `GITHUB_TOKEN=$(gh auth token) node scripts/build.mjs` (`--reshoot all` or `--reshoot id1,id2` to retake screenshots).
- `scripts/shots.mjs` screenshots apps with headless Chrome into `thumbs/<id>.webp`; `data/thumbs.json` records when. Apps are re-shot automatically when their repo is pushed.
- `.github/workflows/rebuild.yml` rebuilds every six hours, on every push to `main`, and on manual dispatch, then deploys through GitHub Pages (Actions source).
- Class tags: PSY001 (Intro), PSY157 (Relationships), PSY170 (I/O Psychology), PSY175 (Sexuality), plus Textbook, Teaching tools, and Personal. When it's unclear which class a new app is for, ask Ross rather than guessing.
- Uncurated apps land under "Just added" (the build log and job summary list them). Add each to `data/sites.json` `apps`: an `id`, `repo`, `name`, `path`, `tags`, and a one-sentence summary in the same voice as the others. Embed (720×450 Top Hat) and standalone variants go in that app's `links`, not their own cards.
- Keep non-public pages off the directory with the repo's `ignore` globs: mockups, templates, drafts, review sheets, experiments, and instructor-only dashboards. Use `"shot": { "none": true }` for any app whose screen would show student photos or data.
